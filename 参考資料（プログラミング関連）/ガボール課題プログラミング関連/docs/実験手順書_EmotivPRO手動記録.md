# 実験手順書

## EmotivPRO手動EEG記録・ガボール課題

この手順書は、実験者が当日の操作を順番に確認するためのものです。

- **EmotivPRO**でEEGを手動記録します
- **本アプリ**で課題を表示し、回答時刻を保存します
- 実験後、同じPCの時刻を使ってEEGと回答データを対応づけます

本アプリはEEGを直接取得せず、Cortex APIも使いません。

## 1. 最初に全体の順序を確認する

実験は、必ず次の順序で行います。

```text
PCの時刻を合わせる
        ↓
ヘッドセットを装着し、EEG品質を確認する
        ↓
EmotivPROのRecordを開始する
        ↓
本アプリを起動し、Prepare sessionを押す
        ↓
練習・本番・休憩を行う
        ↓
課題の終了を確認する
        ↓
EmotivPROのRecordを停止する
        ↓
EEGを書き出し、行動データと一緒に保存する
```

### 特に重要な5項目

1. **EmotivPROと本アプリは、必ず同じPCで動かす**
2. **EmotivPROのRecordを開始してから、アプリの`Prepare session`を押す**
3. **練習・休憩・本番を含め、EEGは最初から最後まで1本で記録する**
4. **実験中はPCの時刻・タイムゾーンを変更せず、スリープさせない**
5. **課題の終了を確認してから、EmotivPROのRecordを停止する**

## 2. この手順書で使う言葉

| 表記 | 意味 |
|---|---|
| Console | 実験者が設定や状態を確認する画面 |
| 被験者画面 | ガボール課題が表示される画面 |
| Record | EmotivPROのEEG記録 |
| `Prepare session` | 参加者IDや条件を確定し、保存ファイルを作り始めるボタン |
| `<base>` | そのセッションを識別する共通ファイル名 |
| `behave` | 回答結果や時刻ログを保存するフォルダ |
| `eeg` | EmotivPROから書き出したEEGを保存するフォルダ |
| `Clock drift` | PCの2種類の時計にずれがないかを示す表示 |

`<base>`は次のような名前です。

```text
P001_drops_20260731_140512
```

## 3. 本番までに決めておくこと

次の項目は、実験責任者・解析担当者と事前に決めてください。

- [ ] 参加者IDの付け方
- [ ] `drops`と`control`の割付
- [ ] 点眼の種類・量・タイミング・安全手順
- [ ] Max Angle（最大傾斜角度）
- [ ] Trials / Block（1ブロックの試行数）
- [ ] Blocks（ブロック数）
- [ ] EEGの書き出し形式（CSVまたはEDF）
- [ ] EmotivPROから書き出すデータの種類
- [ ] 除外チャンネルを誰が判断するか
- [ ] Google Driveの保存先
- [ ] 時計ずれや機器トラブルが起きた場合の中止基準

CSVとEDFのどちらを使うか分からない場合は、解析担当者へ確認してください。
実験者の判断だけで形式を変更しないでください。

## 5. 本番前の短いリハーサル

本番で使うPCを使い、少ない試行数で最低1回テストします。

1. Windowsの時刻を同期する
2. EmotivPROでRecordを開始する
3. 本アプリを次の設定で実行する

```text
Trials / Block: 3
Blocks: 2
```

4. 課題を最後まで進める
5. 課題終了後、EmotivPROのRecordを停止する
6. 本番と同じ形式でEEGを書き出す
7. EEGの記録時間が、課題の開始から終了までを含むことを確認する
8. 行動データとEEGの時刻を解析担当者に確認してもらう
9. `clock_drift`や`timezone_change`の警告がないことを確認する
10. Google Driveへアップロードできることを確認する

1つでも確認できない場合は、本番を始める前に原因を解消してください。

## 7. 実験当日の操作

### 手順A: PCを準備する

1. PCと外部画面をAC電源へ接続する
2. Windowsへログインする
3. 不要なアプリを終了する
4. 通知、会議アプリ、スクリーンセーバーを止める
5. **「設定」→「時刻と言語」→「日付と時刻」**を開く
6. 日付、時刻、タイムゾーンが正しいことを確認する
7. **「今すぐ同期」**を押す
8. 実験中にスリープしない設定になっていることを確認する
9. 2画面が「拡張」になっていることを確認する

ここから実験終了までは、時刻同期、時刻変更、タイムゾーン変更を行わないでください。

確認:

- [ ] PCはAC電源につながっている
- [ ] 日付、時刻、タイムゾーンが正しい
- [ ] スリープしない
- [ ] 2画面が拡張表示になっている

### 手順B: ヘッドセットを装着する

1. EmotivPROを起動する
2. ヘッドセットの電源を入れる
3. EmotivPROからヘッドセットへ接続する
4. ヘッドセットを被験者へ装着する
5. 電池残量を確認する
6. コンタクト品質とEEG品質を確認する
7. 必要に応じてセンサーを調整する
8. Raw EEGに明らかな大きいノイズがないことを確認する

品質が悪いチャンネルを残したまま始める場合は、チャンネル名と理由を記録します。

確認:

- [ ] ヘッドセットが接続されている
- [ ] 電池残量に問題がない
- [ ] EEG品質を確認した

### 手順C: EmotivPROのRecordを開始する

1. EmotivPRO左下の**Recordボタン**を押す
2. 記録名を入力する
3. Subject IDを入力する
4. ベースライン記録の有無を、研究計画どおりに設定する
5. **Start Recording**を押す
6. 記録中表示が出ていることを確認する
7. 記録時間が増えていることを確認する
8. EmotivPRO記録名をセッション記録票へ書く

記録名の例:

```text
P001_drops_20260731_1400
```

確認:

- [ ] Recordが開始されている
- [ ] 記録時間が増えている
- [ ] 記録名を記入した

**このRecordは、休憩中も止めません。課題終了まで記録を続けます。**

### 手順D: 本アプリを起動する

EmotivPROが記録中であることを確認してから、`main.py`があるフォルダで
コマンドプロンプトを開き、次を実行します。

```bat
.venv\Scripts\python.exe main.py
```

アプリが開いたら、次を確認します。

- [ ] 設定ファイルエラーが表示されなかった
- [ ] Consoleの日付と時刻が正しい
- [ ] Consoleのタイムゾーンが正しい
- [ ] `Clock drift`が0ms付近である
- [ ] Consoleが実験者画面にある
- [ ] 課題が被験者画面にある
- [ ] EmotivPROは引き続き記録中である

### 手順E: `Prepare session`を押す

Consoleで次を入力します。

1. **Participant ID**
2. **Eye-drop Condition**
3. **Max Angle (deg)**
4. **Trials / Block**
5. **Blocks**

入力した値を、もう一人の確認者がいる場合は読み上げて確認します。

値が正しいことを確認してから、次を行います。

1. **Prepare session**を1回だけ押す
2. Stateが`Prepared`になったことを確認する
3. Session guideに保存先が表示されたことを確認する
4. 表示された`<base>`をセッション記録票へ書く
5. `<base>_checklist.md`が作られたことを確認する

確認:

- [ ] EmotivPROは記録中である
- [ ] 参加者IDと条件は正しい
- [ ] 課題の設定値は正しい
- [ ] Stateが`Prepared`になった
- [ ] `<base>`を記入した

`Prepare session`を押した後は、参加者IDや設定値を変更できません。

入力誤りに気づいた場合:

1. 課題を始めない
2. 本アプリを閉じる
3. EmotivPROのRecordを停止する
4. 作成済みデータを削除せず、「入力誤り」と記録する
5. 手順Cから新しいセッションとしてやり直す

### 手順F: 練習を行う

1. 被験者へ姿勢、視距離、回答方法を説明する
2. **被験者画面を一度クリックする**
3. スペースキーを押し、説明画面を表示する
4. 説明後、スペースキーで練習を始める
5. 縞模様が傾いたら、できるだけ早くスペースキーを押してもらう

練習中は○または×の結果が表示されます。最低30試行を行い、直近5試行の
平均反応時間が1500ms以下になると練習が終了します。

**Consoleをクリックした後は、必ず被験者画面をクリックし直してください。**
クリックし直さないと、スペースキーが反応しません。

### 手順G: 本番ブロックを行う

1. 練習終了メッセージを確認する
2. 被験者画面をクリックする
3. スペースキーで本番を始める
4. Consoleの状態を定期的に確認する
5. EmotivPROが記録中であることを定期的に確認する

本番では○×の結果は表示されません。

休憩:

- 通常の休憩は2分
- 中間ブロック後の休憩は5分
- 残り時間はConsoleに表示される
- EmotivPROのRecordは止めない
- 点眼条件では、承認済みの点眼手順に従う

休憩終了メッセージが出たら、被験者画面をクリックしてからスペースキーを押します。

### 手順H: 課題とRecordを終了する

1. 被験者画面に「全ブロック完了」のメッセージが出たことを確認する
2. Consoleに終了が記録されたことを確認する
3. Consoleに保存エラーが出ていないことを確認する
4. EmotivPROへ戻る
5. EmotivPRO左下の**Stopボタン**を押す
6. Recording一覧に対象記録があることを確認する
7. 記録時間が実験時間より短くないことを確認する

確認:

- [ ] 課題が正常終了した
- [ ] 保存エラーがない
- [ ] 課題終了後にRecordを停止した
- [ ] EmotivPROに記録が残っている

## 8. EEGを書き出す

### Raw EEGを確認する

1. EmotivPROのRecording一覧を開く
2. 今回の記録を選ぶ
3. 記録を再生する
4. Raw EEGを確認する
5. 接触不良、大きな連続ノイズ、信号の飽和などを確認する
6. 除外候補のチャンネル名と時間を書く

元データは、その場で削除・加工しないでください。

### エクスポートする

1. Recording一覧で今回の記録を選ぶ
2. **Exportアイコン**を押す
3. 事前に決めたデータの種類を選ぶ
4. 事前に決めた形式（CSVまたはEDF）を選ぶ
5. 保存先を指定する
6. エクスポートを実行する
7. ファイルサイズが0バイトでないことを確認する
8. 書き出したファイルを開けることを確認する

複数のファイルが書き出された場合は、どれも削除しないでください。

### ファイル名を揃える

主となるEEGファイルを、次の名前に変更します。

```text
<base>_eeg.<拡張子>
```

次のフォルダへ置きます。

```text
data\<Participant ID>\<YYYYMMDD>\eeg\
```

完成例:

```text
data\P001\20260731\eeg\P001_drops_20260731_140512_eeg.csv
```

付属ファイルがある場合は、内容が分かる名前を付けます。

```text
P001_drops_20260731_140512_eeg_motion.edf
P001_drops_20260731_140512_eeg_export_info.json
```

EmotivPROの元の記録名と、保存した全ファイル名を`<base>_checklist.md`へ書きます。

## 9. 保存データを確認する

正常終了時は、おおむね次のファイルができます。

```text
data\<Participant ID>\<YYYYMMDD>\
├── behave\
│   ├── <base>_meta.json
│   ├── <base>_checklist.md
│   ├── <base>_events.csv
│   ├── <base>_practice_results.csv
│   └── <base>_block<N>_results.csv
└── eeg\
    ├── <base>_eeg.<拡張子>
    └── 必要に応じた付属ファイル
```

チェック:

- [ ] `_meta.json`がある
- [ ] `_checklist.md`がある
- [ ] `_events.csv`がある
- [ ] 練習結果CSVがある
- [ ] 予定した数のブロック結果CSVがある
- [ ] EEGファイルがある
- [ ] EEGファイルが0バイトではない
- [ ] EEGファイルを開ける
- [ ] EEGの記録時間が課題の開始から終了までを含む
- [ ] 除外候補チャンネルを記入した
- [ ] 実験中のトラブルや中断を記入した

## 10. 異常が起きたとき

### まず行うこと

| 状況 | 最初の対応 |
|---|---|
| スペースキーが効かない | 被験者画面をクリックする |
| EEG品質が悪くなった | Consoleの`Pause`を押す |
| `Clock drift`が赤い | 時刻を直さず、値と時刻を記録する |
| EmotivPROのRecordが止まった | Consoleの`Pause`を押す |
| 被験者が中断を希望した | Consoleの`Abort`を押す |
| アプリが終了した | EmotivPROのRecordを停止する |
| 保存エラーが出た | `Pause`し、エラー画面を記録する |

どの場合も、作成済みのデータを削除・上書きしないでください。

### スペースキーが効かない

被験者画面を一度クリックしてから、スペースキーを押します。

### EEG品質が悪くなった

1. Consoleで**Pause**を押す
2. 発生時刻とチャンネル名を書く
3. センサーを調整する
4. EmotivPROが記録中であることを確認する
5. Consoleで**Resume**を押す
6. 被験者画面をクリックする

Pause中もEmotivPROのRecordは続けます。

### `Clock drift`が赤くなった

1. 実験中にPCの時刻を直さない
2. 表示された値と発生時刻を書く
3. 事前に決めた基準に従い、継続または中断する
4. セッション後、解析担当者へ伝える

### タイムゾーン変更の警告が出た

実験中にタイムゾーンを元へ戻さないでください。警告時刻を記録し、事前に決めた
基準に従って中断を判断します。解析担当者へ必ず伝えてください。

### EmotivPROのRecordが途中で止まった

1. Consoleで**Pause**を押す
2. Recordが止まった時刻を書く
3. データを削除しない
4. 事前に決めた基準に従い、中断または新しいセッションとして再開する

複数のEEG記録を、説明なしに1本の記録として扱わないでください。再開した場合は、
すべてのファイル名と記録時間をチェックリストへ書きます。

### 本アプリが終了した

1. EmotivPROのRecordを停止する
2. 発生時刻とエラー内容を書く
3. すでに保存された`data`を削除しない
4. EEGをエクスポートする
5. 再実施する場合は、新しいセッションとして最初から行う

### Consoleに保存エラーが出た

1. Consoleで**Pause**を押す
2. エラー画面を撮影するか、表示内容を書き写す
3. アプリとPCをすぐに終了しない
4. 保存先の空き容量を確認する
5. 責任者へ連絡する

### 被験者都合で中断する

1. Consoleで**Abort**を押す
2. 中断データが保存されたことを確認する
3. EmotivPROのRecordを停止する
4. EEGをエクスポートする
5. 中断理由を書く

## 11. Google Driveへ保存する

1. `behave`フォルダをアップロードする
2. `eeg`フォルダをアップロードする
3. `<base>_checklist.md`が含まれていることを確認する
4. Drive上でファイル名とファイルサイズを確認する
5. 参加者ID、条件、`<base>`、特記事項を解析担当者へ伝える

Google Drive上のファイルを確認するまで、PC内の元データを削除しないでください。

## 13. 解析担当者向けの時刻情報

EEGとの対応づけには、PCの通常時刻を記録した次の列を使います。

- `<base>_events.csv`の`SysUnixTime(ms)`
- `*_results.csv`の`TiltOnsetSys(ms)`
- `*_results.csv`の`KeyPressSys(ms)`

次の列は、反応時間やイベント間隔を正確に計算するための別の時計です。
EmotivPROの絶対時刻との直接対応には使いません。

- `UnixTime(ms)`
- `TiltOnset(ms)`
- `KeyPress(ms)`

`RT(ms)`は、キーが押されるまでの反応時間です。

`events.csv`の`clock_drift`と`timezone_change`も確認してください。

過去の検証では同期精度は概ね±10msでしたが、これは保証値ではありません。
セッションごとに実データを確認してください。
