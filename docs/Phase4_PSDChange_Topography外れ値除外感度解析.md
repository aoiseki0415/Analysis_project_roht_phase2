# Phase 4 PSD Change topography：500%外れ値除外感度解析

## 目的

No1_sub～No3_subのGrand-average topographyでは、単一chだけが極端に着色される、または全頭が同じ方向へ着色される結果があり、事前に想定した領域特異性を評価しにくかった。本解析は、Set 1基準のPSD Changeが極端な被験者ペア×ch×Setを除外し、その影響を確認する追加の感度解析である。元のGrand-average topographyは上書きせず、外れ値除外版を別ファイルとして残す。

## 原因と解釈

PSD Changeは、セッションID・chごとに次式で計算する。

`PSD Change (%) = (Set平均PSD / Set 1平均PSD − 1) × 100`

この比率は、Set側のPSDが大きい場合だけでなく、Set 1平均PSDが小さい場合にも大きくなる。さらに、Grand-averageは被験者ペア間の算術平均であるため、局所的な極端値に引っ張られる。したがって、外れ値は元図の局所ピークや全体的な偏りの一因と考えられるが、外れ値だけで6図の全空間パターンを説明できるとは断定しない。

## 確定した除外規則

- 入力：Phase 4 No1／No2／No3で保存済みの、Phase 1区間maskとセッションID×ch別log10上側3SD mask適用後の未平滑PSD cache。Welch PSDは再計算しない。
- 判定値：各条件のセッションID×ch×Setの平均PSD Change。
- 自動除外：Set 2～6で `PSD Change >= +500%`。これは、そのSet平均PSDがSet 1平均PSDの6倍以上であることを意味する。
- 対応の維持：Eye DropまたはControlのどちらか一方が基準を満たした場合、その被験者ペア×ch×Setを両条件の比較から除外する。
- 持続的異常：同じセッションID×chが2 Set以上で基準を満たした場合、その被験者ペア×chをSet 2～6のすべてから除外する。
- 集団平均：除外後はSet×chごとに有限値を持つ被験者ペアだけで平均する。あるchの除外を理由に、同じ被験者の他chまでは除外しない。
- Set 1：baselineでありPSD Changeは平均0%になるため、自動除外の判定対象外。
- 既知欠測：従来どおり、ペア109–209はSet 1欠測のためsub解析全体から除外し、その他の既知欠測Setは対応条件側も同じSetから除外する。
- 絶対PSD：低いSet 1分母か高いSet側PSDかを判断する診断情報として確認するが、自動除外条件には使用しない。

500%基準の該当率は、各解析12,384セル中、No1が17セル（0.137%）、No2が23セル（0.186%）、No3が17セル（0.137%）であり、上側約0.1～0.2%だけを対象とする保守的な基準である。

## 成果物

実装：`解析プログラム/Phase4_脳波解析/Phase4_PSDChange500OutlierExcludedTopography.py`

各Noの既存 `Topography/GrandAverage/` に、次の命名規則でCキューブとVロートプレミアムの計6 PNGを追加する。

`<No_sub>_Topography_GrandAverage_<Product>_PSDChange500pctOutlierExcluded.png`

この追加図は外れ値感度を確認するための結果であり、元のGrand-average topographyを削除・置換しない。また、除外後に事前仮説どおりの領域特異性が現れることを保証する解析ではない。
