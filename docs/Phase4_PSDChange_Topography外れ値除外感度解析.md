# Phase 4 PSD Change topography：500%＋空間外れ値除外感度解析

## 目的

No1_sub～No3_subのGrand-average topographyでは、単一chだけが極端に着色される、または全頭が同じ方向へ着色される結果があり、事前に想定した領域特異性を評価しにくかった。本解析は、Set 1基準のPSD Changeが極端な被験者ペア×ch×Setを500%基準で除外した後、周辺電極と不連続な単一chを空間外れ値として追加除外し、その影響を確認する感度解析である。元の主要Grand-average topographyは上書きしないが、先行して作成した500%除外版6枚は同名で本二段階除外版へ更新する。

## 原因と解釈

PSD Changeは、セッションID・chごとに次式で計算する。

`PSD Change (%) = (Set平均PSD / Set 1平均PSD − 1) × 100`

この比率は、Set側のPSDが大きい場合だけでなく、Set 1平均PSDが小さい場合にも大きくなる。さらに、Grand-averageは被験者ペア間の算術平均であるため、局所的な極端値に引っ張られる。したがって、外れ値は元図の局所ピークや全体的な偏りの一因と考えられるが、外れ値だけで6図の全空間パターンを説明できるとは断定しない。

## 確定した二段階除外規則

### 共通入力

- 入力：Phase 4 No1／No2／No3で保存済みの、Phase 1区間maskとセッションID×ch別log10上側3SD mask適用後の未平滑PSD cache。Welch PSDは再計算しない。
- 判定値：各条件のセッションID×ch×Setの平均PSD Change。
- Set 1：baselineでありPSD Changeは平均0%になるため、両段階とも判定対象外。
- 既知欠測：従来どおり、ペア109–209はSet 1欠測のためsub解析全体から除外し、その他の既知欠測Setは対応条件側も同じSetから除外する。

### 第1段階：条件別500%基準

- 自動除外：Set 2～6で、各条件のセッションID×ch×Set平均が `PSD Change >= +500%`。これは、そのSet平均PSDがSet 1平均PSDの6倍以上であることを意味する。
- 対応の維持：Eye DropまたはControlのどちらか一方が基準を満たした場合、その被験者ペア×ch×Setを両条件の比較から除外する。
- 持続的異常：同じセッションID×chが2 Set以上で基準を満たした場合、その被験者ペア×chをSet 2～6のすべてから除外する。
- 絶対PSD：低いSet 1分母か高いSet側PSDかを判断する診断情報として確認するが、自動除外条件には使用しない。

### 第2段階：被験者ペア×Set内の空間外れ値

1. 第1段階適用後、被験者ペア・Set・chごとに `D = Eye Drop PSD Change − Control PSD Change` を計算する。
2. MNEの標準電極座標に基づき、各chの3次元距離が近い4電極を固定近傍とする。
3. 各chについて `空間残差 = D(ch) − 近傍4電極の有限値中央値` を計算する。近傍の有限値が3個未満なら、そのchは空間判定しない。
4. 同一被験者ペア×Setの最大32個の空間残差から、残差中央値とMADを求める。有限残差が8個未満、またはMADが実質0なら空間判定しない。
5. `spatial robust z = (空間残差 − 残差中央値) / (1.4826 × MAD)` とし、`|spatial robust z| > 5` のchを除外する。
6. 除外単位は、その被験者ペア×ch×Setだけとする。空間判定を理由に他Set、他ch、被験者全体を除外せず、持続異常規則も追加しない。

近傍電極との差を使うことで、前頭・後頭など複数電極に連続する広い変化は残し、周囲から孤立した一電極ピークを対象にする。robust zの5は公式規定値ではなく、3.5／4／5／6の探索比較と、500%除外後にも残った代表的な6つの局所ピークがすべて5を超えたことから、保守的な全対象共通値として採用した。

### 集団平均と記録

- 二段階除外後、Set×chごとに有限値を持つ被験者ペアだけで算術平均する。あるchの除外を理由に、同じ被験者の他chまでは除外しない。
- 第1段階と第2段階の該当セルは別CSVに保存し、第2段階では条件差、近傍中央値、空間残差、MAD、robust zを記録する。
- 実行要約JSONには両段階の除外数、パラメータ、有効N範囲、PSDを再計算していないことを保存する。

500%基準の該当率は、各解析12,384セル中、No1が17セル（0.137%）、No2が23セル（0.186%）、No3が17セル（0.137%）であり、上側約0.1～0.2%だけを対象とする保守的な基準である。500%除外後の条件差に空間判定を適用した結果、No1は189セル、No2は195セル、No3は158セルが追加除外された。

## 成果物

実装：`解析プログラム/Phase4_脳波解析/Phase4_PSDChange500OutlierExcludedTopography.py`

各Noの既存 `Topography/GrandAverage/` にある、次の命名規則のCキューブとVロートプレミアム計6 PNGを二段階除外版で上書きする。ファイル名は過去の500%版との連続性のため維持する。

`<No_sub>_Topography_GrandAverage_<Product>_PSDChange500pctOutlierExcluded.png`

監査表は各Noの `Sub/tables/PSDChange500pctAndSpatialMAD5OutlierExclusion/` に保存する。

この追加図は外れ値感度を確認するための結果であり、元の主要Grand-average topographyを削除・置換しない。また、除外後に事前仮説どおりの領域特異性が現れることを保証する解析ではない。外れ値判定は仮説に合う領域を残すためではなく、事前固定した数値規則だけで行う。
