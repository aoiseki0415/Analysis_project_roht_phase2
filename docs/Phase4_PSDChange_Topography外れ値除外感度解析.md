## 2. 入力・指標・参照分布

### 2.1 入力と表示値

1. 各帯域80 HDF5を読込時に検証する。実周波数bin・設定・256 Hz・32ch名順・保存mask・manifestのID／条件／製品・既知欠測を照合する。別帯域cacheで代用しない。
2. Phase 1除去区間と1%以上重なるPSD窓のmask、各帯域固有のID×ch・全Set一括log10上側3SD maskを再適用した**未平滑PSD**を使う。60秒平滑化後の値は使わない。
3. セッションi・Set s・ch cごとに、有限PSD窓Pの算術平均A、中央値D、有限点数nを計算する。同条件・同ch自身のSet 1算術平均をBとする。
4. R=A/B、Set平均PSD Change=100×(R−1)。各ペアの表示値は100×(R_EyeDrop−R_Control)。従来の未平滑Change時間平均後の条件差と同値で、中央値baselineへ置き換えない。
5. 条件側のR/D/H/Qで異常判定を行い、その後に条件差を群集計する。条件差の値・符号・有意差を判定へ入力しない。

**既存cache署名の互換検証：** No1 cacheはGit `3c7c25b`時点の署名schemaで作られ、`analysis_stem`／`focus_channel`の2キーをまだ含まない。No1だけはその既知schemaで期待hashを復元し、保存hashへ厳密照合する。No2・No3は各帯域の現行schemaを使う。帯域・ch・単位・既存mask等の属性検証は別に全件行い、hash検証を省略しない。cache本体・PSD・保存閾値を書き換える互換処理ではない。

| 指標 | 定義・用途 |
|---|---|
| R | A/B。Set 1に対するChangeの空間的孤立 |
| D | Set内の有限PSD中央値。絶対PSDの空間的孤立 |
| H | A/D。平均が大きなPSDに左右される程度 |
| Q | 有限n点の上位ceil(0.10×n)点の総和／全有限PSD総和。時間的集中 |

比・対数は有限かつ正の値だけで計算する。PSDへの微小定数加算、欠測のゼロ置換、時刻の詰め直しはしない。Qは実時間率ではなく、有限PSD窓数とそのパワー総和に基づく。計算不能な指標は監査に残す。

### 2.2 近傍とrobust z

- 既存MNE `colin27_1020` montageの**3Dユークリッド距離**による最近傍4chを、各ch自身を除いて固定する。2D描画円の端や画素から近傍を決めない。
- X=RまたはDについて、近傍jとの対数差は d_j=log2(X_c)−log2(X_j)。
- 局所残差 L=log2(X_c)−median(log2(X_近傍4ch))。中央値後に対数化する方式とは異なる。
- robust z=(x−median(x))/max(1.4826×median(|x−median(x)|),0.15)。有限値で中央値・MADを求める。0.15は尺度下限でありPSDへの加算値ではない。
- **空間z**：同じセッション・同じSetの32chのLが参照集合。
- **cohort残差z**：同じ帯域・Set・chのLについて、baseline適格な両製品・両条件の全セッションが参照集合。
- **絶対PSD水準z／平均中央値z**：同じ帯域・Set・chのlog2(D)／log2(H)をcohort参照とする。

各帯域の元の適格poolで参照分布を1回固定し、候補を取り除いて再推定しない。No1・No2・No3・No10の値をプールしない。両条件を参照集合に含めても、判定対象は各条件個別、群平均は製品別である。

## 3. 最新の確定除外規則

### 3.1 維持する3経路（No10 v2と同じ）

各行の条件はすべてAND。3経路と第3.2節の追加経路をOR結合する。

| 経路 | AND条件 |
|---|---|
| Change空間的孤立：Set 2–6 | abs(L_R)≥log2(1.5)、abs(空間z)≥4.5、abs(cohort残差z)≥4.5、4近傍中3ch以上へL_Rと同方向に1.25倍以上、かつ下記の厳格近傍条件 |
| 絶対PSD空間的孤立：Set 1–6 | abs(L_D)≥2（4倍差）、abs(空間z)≥4.0、abs(cohort残差z)≥3.5、abs(絶対PSD水準z)≥4.0、4近傍中3ch以上へL_Dと同方向に2倍以上、かつ下記の厳格近傍条件 |
| 時間的集中：Set 1–6 | Q≥0.50、H≥3.0、平均／中央値z≥3.5 |

同方向とは、L>0ならd_j≥log2(倍率)、L<0ならd_j≤−log2(倍率)が3ch以上。各zの符号一致を追加要求しない。

**厳格近傍条件は空間2経路だけに適用：** 近傍4値をx(1)≤x(2)≤x(3)≤x(4)としたとき、X_c>2×x(3)、またはX_c<x(2)/2。少なくとも3近傍から同方向へ**厳密に2倍超**離れることを要求する。ChangeではX=R、絶対PSDではX=D。時間経路にこの条件は要求しない。

### 3.2 v3追加Change空間経路：Set 2–6

次のすべてをANDで要求する。

| 観点 | 固定条件 |
|---|---|
| 自身のbaselineからの変化 | R>2またはR<0.5。境界2／0.5は含めない |
| 局所孤立 | 最近傍4ch中3ch以上から同方向へ**厳密に1.8倍超** |
| cohort残差 | abs(cohort残差z of L_R)≥6 |
| 追加支持 | abs(空間z of L_R)≥3 **または** 同方向3/4近傍から**厳密に3倍超** |

倍率fの判定は、4近傍が有限・正の場合はR_c>f×R_(3)またはR_c<R_(2)/f。実装では有限・正の近傍だけを支持票とし、少なくとも3票を要求する。欠測・非正値を0や支持票として補わない。1.8倍と3倍は独立評価し、高低両方向に同一基準を使う。3倍のOR支持でも、cohort z≥6・自身のR・1.8倍条件は省略しない。

旧Change空間経路のz=4.5を一律に3へ緩めるのではない。既存3経路を数値・境界とも保持し、新経路の該当を加える。全ch・全セッションへ同じ規則を適用し、頭頂／端、個人、製品ごとの閾値調整は行わない。

**使用しない基準：** 旧60秒block持続上昇／低下、固定500%／800%、個人図の色軸上限、旧No1–3の除外mask、被験者全体の一律除外、線図／定量化の指定除外、条件差やp値による判定。

### 3.3 Set 1・paired OR・群平均

1. 条件側のセッション×ch×Setで各経路を判定。
2. Set 1で絶対PSD空間経路または時間経路に該当した場合、baselineへの懸念として**同じセッション・同じchのSet 2–6**へ伝播。Set 1のR=1にChange判定はしない。
3. どちらかの条件が該当したペア×ch×Setを両条件から除外。別ch・別ペアへ拡大しない。
4. Set 1 topographyは従来の0を保持する。baseline判定の伝播とSet 1の表示は区別。
5. 元欠測は新規除外数に含めない。除外率の分母はSet 2–6で元から有限なペア×ch×Set。
6. 残存する被験者内差を製品×Set×chで等重み平均する。chごとのN・構成員を保存する。原図の全32ch有限ペア方式自体は変更しない。

## 7. 解釈上の限界

- 結果を見た後の探索的・事後感度分析。No10から同じ規則を移したことは、他帯域での独立した妥当性検証を意味しない。
- 局所的な真の生理変化を除く可能性、空間的に滑らかなノイズ・持続異常が残る可能性がある。候補外は正常の証明ではない。
- 頭皮円周の色には補間も関与する。実電極値・近傍・条件側指標を確認し、存在しない電極を円周色から推定しない。
- 除外後はchごとにN・構成員が変わる。色軸も再計算するため、色だけで改善を判断しない。
- 主線図・定量化とは対象集合が異なる場合がある。それらを今回黙って変更せず、原図と追加図を併記する。
