# Phase 4 PSD Change topography：条件別・双方向外れ値除外感度解析

## 目的と位置づけ

No1_sub～No3_subの主要Grand-average topographyには、単一chだけが極端に着色される箇所があった。原因として、個別セッションの一部chで、(1) Set 1から絶対PSDが過大、または (2) Set 1後に長時間の上昇・信号消失を伴う低下が続く場合に、被験者間算術平均が引っ張られることを確認した。

本解析は、この2点を条件別に検査する追加感度解析である。仮説に合う電極を選ぶ処理ではない。元の主要Grand-average topography、PSD cache、個人結果は変更せず、追加figureと監査表だけを更新する。

過去に試した「+500%基準＋条件差に対する空間MAD判定」は確定規則ではない。条件差を作った後の判定では異常条件を特定できず、正負の反対側や持続的低下を十分扱えなかったため、現行規則では使用しない。

## 共通入力と単位

- 入力：No1／No2／No3の保存済み未平滑PSD cache。Welch PSDは再計算しない。
- cacheにはPhase 1区間maskと、セッションID×ch別・全Set一括の `log10(PSD)` 上側3SD maskが適用済み。
- No1：4–7 Hz、No2：8–15 Hz、No3：1–3 Hzの帯域平均PSD。
- PSD Change：セッションID・chごとに `(PSD / Set 1有限値平均 − 1) × 100`。
- 条件差：`Eye Drop PSD Change − Control PSD Change`。
- ペア109–209はSet 1欠測のためsub解析全体から除外する。その他の既知欠測Setは従来どおり対応条件側も除外する。

## 判定の原則

1. Eye DropとControlを必ず別々に判定する。
2. Set 1絶対PSD、持続的上昇、持続的低下を別経路で判定する。
3. 片条件で該当したら、同一被験者ペア×ch×Setを両条件から除外する（paired OR）。
4. 他ch、他Set、被験者全体へは自動拡張しない。ただしSet 1絶対PSD高値はそのchの基準自体が不適切なため、同一ペア×chのSet 2～6を除外する。
5. robust zは中央値と `1.4826×MAD` を用いる。絶対PSDと比率は正の歪んだ分布のため、`log10` 後にrobust zを計算する。

## 確定した判定規則

### 方向1：Set 1絶対PSD高値

セッションID×chのSet 1未平滑PSD中央値を求め、同じ解析・chの全セッション分布と、標準電極座標で近い4電極の中央値を比較する。次をすべて満たす場合、その被験者ペア×chのSet 2～6を除外する。

- Set 1絶対PSDの `log10` robust z `> 4.5`
- 同じchの全セッション中央値の `2.5倍以上`
- 近傍4電極中央値の `2.0倍以上`

低いSet 1だけでは自動除外しない。低い分母が後続Setの見かけの増加を作った場合は、次の持続的上昇経路で評価する。

### 方向2a：持続的上昇

各Setを実時間60秒の非重複blockへ分け、各blockのPSD中央値を同じセッションID×chのSet 1 PSD中央値で割る。次のいずれかを満たせば、その被験者ペア×ch×Setを除外する。いずれも2倍以上のblockが2区間以上連続することを必須とする。

- 中央傾向経路：block比中央値の `log10` robust z `> 3.5`、block比中央値 `>= 2.5`、2倍以上block率 `>= 50%`
- 上側占有経路：block比75パーセンタイルの `log10` robust z `> 3.5`、75パーセンタイル `>= 3.0`、2倍以上block率 `>= 40%`
- 空間裏付け経路：block比中央値 `>= 2.5`、2倍以上block率 `>= 50%`、Set絶対PSDが同じchの全セッション中央値の `2.5倍以上`、かつ近傍4電極中央値の `2.0倍以上`

空間裏付け経路は、No3 Cキューブ Set 4のF4のように、時間方向のrobust zが3.5直下でも、持続性と局所絶対PSD高値が同時に確認できるセルを扱うために設ける。

### 方向2b：持続的低下

単独条件のPSD Changeの理論下限は−100%であり、条件差で観察される−500%等をそのまま条件別閾値にはしない。Set 1後の低下を「信号が十分取れていない可能性」として除外するには、時間方向の低下と絶対PSD低値を同時に要求する。次をすべて満たす場合、その被験者ペア×ch×Setを除外する。

- block比中央値 `<= 0.30`
- Set 1の0.5倍以下のblock率 `>= 60%`
- 0.5倍以下のblockが2区間以上連続
- Set絶対PSDの `log10` robust z `< −4.0`
- 同じchの全セッション中央値の `0.35倍以下`
- 近傍4電極中央値の `0.45倍以下`

## 集団平均、除外率、N

- paired OR適用後、製品群×Set×chごとに有限値を持つ被験者ペアで算術平均する。
- 除外率の分母は、Set 2～6で条件差が有限な被験者ペア×ch×Setセル数。元から欠測のセルは新規除外数へ数えない。
- 探索時の目安は全体約3%。N=15は望ましい目安であって絶対条件ではない。
- 確定規則の実測は、No1 155/6,144（2.523%）、No2 182/6,144（2.962%）、No3 173/6,144（2.816%）、合計510/18,432（2.767%）。最小有効Nは15。

## 定性的figure評価

数値だけで方法を採用せず、6枚すべてについて、単一電極の孤立色、隣接電極間の急反転、全頭的偏りを確認した。これは統計検定ではなく、感度解析の表示品質と残存リスクの記述である。

| 解析 | 製品 | 評価 |
|---|---|---|
| No1 Fmθ | Cキューブ | 主要な孤立ピークは縮小し、残存分布は概ね広く連続的。 |
| No1 Fmθ | Vロートプレミアム | 後半Setの正方向は単一chではなく広域分布。支配的な孤立chは認めない。 |
| No2 後頭alpha | Cキューブ | 負方向の分布は広域で、初期図の局所極端値は縮小。 |
| No2 後頭alpha | Vロートプレミアム | 大きな孤立極端値は縮小したが、頭部周縁の赤青交代が残るため、6図中で最も慎重な解釈が必要。 |
| No3 前頭delta | Cキューブ | Set 4 F4の単独支配は縮小。局所構造は残るが、当該一人・一chの極端値支配ではない。 |
| No3 前頭delta | Vロートプレミアム | 後半Setは前方正・後方負の広い勾配で、単一ch極端値ではない。 |

したがって、外れ値による局所支配は改善したが、仮説どおりの領域特異性が証明されたとは扱わない。特にNo2 Vロートプレミアムは残存空間構造を限界として報告する。
