4. 入力はPhase 1のセット別「脳活動解析用」HDF5。確定済みのフィルタ・トレンド除去・ICA処理後EEGと不良時間maskを読み取り専用で使う。瞬き成分の復元信号、No1–7の帯域平均PSD cacheは使わない。追加フィルタ・再参照・再ICAはしない。
5. `fs=256 Hz`、等間隔sample、時刻、Set番号、Pz/Fz列、単位を照合する。時間窓の境界はPhase 1の `time/relative_seconds`（sample番号/256）に基づく。これはNo1–7と同じsample clockであり、各間隔が1/256秒であることを検証する。`OriginalTimestamp`は無線計測由来の間隔揺れを含むため、有限・厳密単調増加・信号との行数一致を確認して出典情報として保持し、等間隔と仮定したり再サンプリングしたりしない。異なるfsを256 Hzとみなさない。入力がVならµVへ変換し、PSDをµV²/Hzへ統一する。二重変換しない。
6. Phase 1でICA学習から除外されたchも、最終入力に信号が保持されていれば使う。ただし通常chと同じICA成分除去が適用されたとは扱わず、QCへ記録する。利用不能chは理由付きNaNとし、別chで代替しない。
7. 既存個人図では、欠測Setは当該条件だけ未描画。対応条件が存在すれば描き、paired ORによる追加欠測化はしない。Set 1欠測でもペア全体は除外しない。NaNを0 Hz、10 Hz、隣接値で補完しない。新たな差分Grand-averageの基準区間・対応欠測規則は第10節に限って適用し、個人図へ逆適用しない。

## 3. 推定区間とWelch内部窓

**IAFの推定区間**はSet全体。**Welch内部のsegment**はその中の10秒窓。区間内の有効periodogramを平均して1本のPSDを作り、1つのIAFを求める。10秒ごとのIAFを平均する方法ではない。

### 3.1 区間の定義

- No8・No9ともSetの開始から終了までを対象とする。冒頭60秒だけではない。
- sample支持区間は `[0,N/fs)`。各Set先頭から10秒窓を5秒間隔で置く。
- Set境界を越える窓、末尾の不完全窓、paddingは使わない。末尾の未使用長も記録する。「Set全体を対象にしたWelch推定」は全sampleが必ず採用されるという意味ではない。
- Set 1〜6の6位置を保持し、欠測を詰めない。前半／後半への分割、12値化、60秒移動IAFは現行解析では行わない。

### 3.2 PSDのパラメータ

| 項目 | 設定 | 理由・意味 |
|---|---|---|
| 計算法 | 有効な修正periodogramの算術平均 | Welch平均PSDを不良窓を除いて計算 |
| 関数 | `scipy.signal.periodogram`を各有効窓へ適用 | 不良sampleを含む窓だけを除ける |
| `fs` | 256 Hz、入力属性から検証 | 時間・周波数軸の整合 |
| 窓長 | 10秒＝2560 samples | 実測長からFFT bin間隔0.1 Hz |
| 窓形状 | `get_window('hann',2560,fftbins=True)` | periodic Hannを明示 |
| 窓間隔 | 5秒＝1280 samples | 50% overlap |
| `nfft` | 2560、zero paddingなし | 0.1 Hz bin |
| `detrend` | `'constant'` | 各窓の平均を除く |
| PSD | `return_onesided=True, scaling='density'` | 片側密度、µV²/Hz |
| 数値精度 | EEGをfloat64へ変換してからV→µV換算、計算・保存もfloat64 | 単位換算時の不要なfloat32丸めを避ける |
| 平均 | 線形PSDの算術平均 | median、log平均、IAF値の平均ではない |
| 保存周波数 | 1.0–40.0 Hz、0.1 Hz刻み、両端含む391 bins | 描画・帯域端の判定・再利用 |
| 描画周波数 | 1.0–30.0 Hz、両端含む | 指定のスペクトル表示 |
| ピーク探索 | 8.0–15.0 Hz、両端含む | 本解析のalpha定義 |

不良窓がない場合、同じ明示Hann窓を渡した `scipy.signal.welch(fs=256,nperseg=2560,noverlap=1280,nfft=2560,detrend='constant',scaling='density',return_onesided=True,average='mean')` と一致することをテストする。全PSDを計算後に1–40 Hzへ切り出す。

0.1 Hzは**bin間隔**であり、生理的ピークを0.1 Hz精度で識別できる保証ではない。10秒はこの間隔を得る設計判断であり、IAFに唯一の標準窓長があるという主張ではない。Hann・50% overlapの参照：[SciPy Welch](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)。

### 3.3 Phase 1不良区間

Phase 1の不良時間maskに**1 sampleでも**重なる10秒窓は全体を不採用。対象chに非有限sampleがある窓も除く。元の時間位置を保ち、不良区間を詰めて連結しない。NaN入り全区間を通常のWelchへ渡すだけで自動除外されるとは想定しない。

有効窓が1つ以上なら計算する。有効窓数、unique coverage（有効窓の時間区間の和集合）、元区間に対する割合を記録するが、最低60秒・6窓・35秒・有効率の追加足切りはしない。有効窓0ならPSD・IAFはNaNとし、短時間／全窓不良などの理由を分ける。PSDが作れても局所ピークがなければIAFだけNaN。

No1–7の帯域平均PSD時系列へ行うlog10上側3SD除外は追加しない。時間方向のPSD外れ値除外と、平均スペクトル上のピーク探索を混同しない。

## 4. 周波数平滑化とIAF：平滑化PSDの局所ピーク

1. 推定区間内の有効periodogramを**周波数binごとに先に平均**し、未平滑の線形平均PSDを保存する。
2. 1–40 Hzの平均PSDへ、周波数方向の**中心化5点・等重み単純移動平均を1回だけ**適用する。時間方向・Set間・条件間・ch間では平均しない。0.1 Hz grid上の `[f−0.2,f−0.1,f,f+0.1,f+0.2]` を平均するため、相談した「前後0.25 Hz以内」を満たす。bin中心間の幅は0.4 Hz、5 binsとしての公称幅は0.5 Hz。0.1 Hz刻み自体は変えない。
3. 周波数配列の両端は存在する点だけで平均（最端3点、その隣4点）。zero/reflect paddingをせず、1–40 Hz全域で平滑化した後に表示帯域・alpha候補を選ぶ。8/15 Hzを平滑化配列の端にしない。有効窓0の全NaN PSDは全NaNのまま。部分的な非有限PSDを近隣値で埋めず、入力異常として停止する。
4. **平滑化済み**1–40 Hz PSDへ `scipy.signal.find_peaks` を適用し、8–15 Hz内の局所最大のうち、**平滑化PSDの高さが最高**の候補を選ぶ。`height, prominence, distance, width, threshold`等の足切りは渡さない。8.0・15.0 Hzも外側の7.9・15.1 Hzとの比較で局所最大なら候補。同高なら低周波数側。plateauはSciPyの規則（中央、偶数長は低index側）に従う。
5. 0.1 Hz gridで出力し、放物線補間やGaussian fittingはしない。局所最大なしは理由付きNaN。帯域内argmaxで端を無条件選択しない。左・中央PSD、右IAF、候補峰と選択峰PSDの表・cacheは**同じ1回平滑化済みPSD**に基づく。描画時の再平滑化・未平滑へのfallbackは禁止。

内部binでは `S[j] = (P[j−2]+P[j−1]+P[j]+P[j+1]+P[j+2])/5`。ここでPはWelch平均PSD、Sが現行解析のPSD。Setごとの推定なので、各セッション6値を保持する。

### 平滑化の根拠と採用範囲

[Smulders et al. (2018), European Journal of Neuroscience](https://pmc.ncbi.nlm.nih.gov/articles/PMC6221126/)は平均スペクトルを5点移動平均で2回平滑化してからPzの局所最大を選んだ（元bin間隔約0.244 Hz、探索5–15 Hz）。[Corcoran et al. (2018), Psychophysiology](https://pubmed.ncbi.nlm.nih.gov/29357113/)も平滑化後のスペクトルからPAFを推定するが、方法はSavitzky–Golayである。

今回参考にするのは「周波数平滑化後にピーク推定する」という順序と単純移動平均の実例。**0.1 Hz grid・5点・1回・8–15 Hzは本プロジェクトで合意した設定であり、論文と完全同一でも、文献が最適性を保証する幅でもない。** 2回適用・SG・論文のピーク不在時10 Hz補完は採用しない。

**1/f背景除去、log変換、Savitzky–Golay平滑化、z値、ピークの顕著さによる足切り、旧複数峰80%フラグは使わない。** 旧処理を初期値として残さず、新しい計算契約で実装する。

微小な局所峰も採用され得る探索的指標である。NaNを減らす方針は全値の生理的妥当性を保証しない。PSD、候補峰数、選択峰PSD、有効窓量を確認する。1/f、ノイズ、多峰間の切替の影響は残り、注意・眠気・製品効果の直接証明とはしない。

現行で読む `SetN/whole/` 内の `psd`（別名 `window_psd_uv2_hz`）と `mean_psd`（別名 `mean_psd_uv2_hz`）は未平滑。`smoothed_mean_psd_uv2_hz` が現行の描画・ピーク推定用。`peaks/{Pz,Fz}` は平滑化後の結果。別名はHDF5 hard linkで同一原データを指し、重複した数値コピーを作らない。軸順は窓PSDが窓×ch×周波数、平均PSDがch×周波数、ch順はPz/Fz。将来別解析で読む時はraw/smoothedの選択を明示し、平滑化済みに再度適用しない。

## 10. 確定仕様：基準区間からのIAF差分Grand-average

### 10.1 目的・入力・計算

個人ごとの「もともとのピーク周波数」の違いを差し引き、課題進行に伴う周波数変化をEye DropとControlで比較する。各No・各製品群は独立して扱う。全利用可能データ版（`AllAvailable`）を基本とし、第13節で確定した対象の追加選別版（`SelectedParticipants`）も別名で生成する。いずれも既存IAFの読取りから始め、個人解析の再実行とは分離する。

入力は、現行v3解析がすでに出力した区間別IAF（No8・No9とも各セッション6値）。各Noの `Sub/tables/No<番号>_IAF_Estimates.csv` と対応cacheを照合して使う。元EEGからのWelch再計算、PSD平均後の新たなピーク抽出、窓別ピークの平均は行わない。

被験者ペアp、条件c、区間k、基準区間bに対し、次を計算する。

`IAF Change[p,c,k] = saved IAF[p,c,k] − saved IAF[p,c,b]`

| No | ch | 基準区間b | 集計する区間 |
|---|---|---|---|
| No8 | Pz | Set 1全体の保存IAF | Set 1–6 |
| No9 | Fz | Set 1全体の保存IAF | Set 1–6 |

Eye DropとControlでそれぞれ自身の基準IAFを引く。単位はHzで、割り算・百分率化・絶対値化はしない。Set 1前半の値や前後半平均を基準にせず、当該chのSet 1全体の保存IAFだけを使う。各区間の利用可能な被験者差分を等重みで平均し、製品群別に2条件の線として表す。基準区間は計算上0 Hz差となる。PSDを先に被験者平均してからピークを求める方法ではない。

### 10.2 利用可能データと被験者内対応

- 基本版は共通対象全員から開始し、No4–7等の事後除外を流用しない。
- 当該Noの基準IAFが片条件でも非有限なら、そのペアは**当該Noの差分Grand-average全体だけ**で利用不能。別Noや元の個人IAF解析からは除外しない。
- 基準が両条件で有限なら、後続区間の片条件欠測は**その区間だけ両条件を群平均から外す**。それ以外の利用可能区間は保持する。欠測を補間せず、有効Nを区間ごとに記録する。
- 各区間の両条件で同じペア集合を使い、Nを一致させる。全6区間が完全であることは要求しない。
- 「基準IAFが有限で差分計算できるか」と「基準に明瞭なalpha峰があるか」は別項目。今回、基準区間の明瞭さを新たな必須採用基準にはしない。
- 既存IAF・PSD・個人PNGは保持する。今後の追加対象版でも、既存の不明瞭区間を消す、再推定する、都合のよい別ピークに置換する処理はしない。

追加選別版は第13節の確定CSV・JSONの対象集合をそのまま使う。その対象の不明瞭区間まで除くC限定処理はしない。採用者についても上記のpaired欠測規則を適用する。統計検定・バーグラフ・条件差の第3線は追加しない。

### 10.3 平均・SEM・figure

- 各No×製品×cohort×区間で同じペア集合の個人差分を条件別に等重み算術平均する。被験者ごとの有効窓数で重み付けしない。
- shadeは条件別の平均±SEM。`SEM = std(個人差分, ddof=1) / sqrt(N)`。N=0は平均・SEMともNaN、N=1は平均だけ有限・SEMはNaN。基準区間は全差分0なのでN≥2なら平均・SEMとも0。
- 正方形の単一パネルPNG（10×10 inch、180 dpi）。既存3パネルの右図を基準に、Arial、軸名28 pt、目盛り20 pt、凡例17 pt、線幅3 pt、marker 10 pt・白枠1 ptとする。Set 1〜6の6位置を詰めず表示する。
- 軸boxは正方形。余白left .17／right .96／bottom .18／top .87、軸名pad 14 pt、軸線1.5 pt、tick長6 pt・幅1.5 pt、上／右spineなし。x範囲は0.75〜区間数+0.25。タイトルはch・製品名とcohortの2行、26 pt・pad 20 pt・行間1.3。凡例は右上・枠なし。保存時のtight cropは使わず1800×1800を保つ。
- 横軸は両Noとも`Set`（1–6）。縦軸は`IAF Change (Hz)`。条件名は`Eye Drop (<製品名>)`と`Control`。統計印・N注記は図へ追加しない。
- 色は既存個人図の各No×製品をそのまま使う。Controlは共通`#402B5D`。shadeは線と同色・alpha 0.18。Setによる濃淡は群平均には使わない。
- y軸は**全8図共通の−1.1〜+1.1 Hz**、目盛りは **−1、−0.5、0、0.5、1 Hz**。旧No8 Vプレ図の見やすさを基準に、No・製品・cohortで上下限を変えない。平均やSEMを表示範囲内に収めるための値のクリップはしない。保存値はそのまま残し、表示範囲を超える場合は監査ログへ件数を記録する。
- 6離散値を線で結ぶだけで、新たな周波数／時間平滑化、progress化、補間はしない。欠測位置を詰めて線でつながない。

## 11. 明瞭な単峰に限定する追加選別の方法

### 11.1 評価目的と独立性

目的は、**alpha帯に一つの山として明瞭なピークが確認できる被験者へ絞った追加Grand-average**を、全利用可能データ版と並べて確認すること。小峰が律動的・櫛状に複数並び、代表となる一つの山が明瞭でない被験者を採用しない。単に局所最大が計算できることや候補峰数だけで単峰性を認定しない。利用者が現行個人図を確認して追加不採用を確定した集合を用いる。

全Setが明瞭であることは新たに要求しない。既存の最低条件（各条件で少なくとも1区間C、両条件のSet 1 IAF有限）を満たしても採用を保証せず、利用者が定めたより厳しい単峰形状の追加除外を優先する。明瞭から不明瞭への変化と、採用者の有限な後続IAFは保持する。

40ペアをNo8（Pz）・No9（Fz）で独立に扱い、各NoをCキューブ／Vロートプレミアムに分ける。旧No10のFz whole観察は新No9へ対応づけ、廃止した半Set観察を混ぜない。Eye DropとControlは条件ごとに確認し、効果の方向、条件間差、望ましい結果を採否の基準にしない。

### 11.2 観察手順と判定基準

1. 現行3パネルPNG、保存済み1回平滑化PSD、保存IAF、候補峰、有効窓量、欠測理由、ICA学習除外chフラグを対応付ける。対象No・ch・製品・2セッションの条件対応を確認する。
2. 各条件の全6区間を確認する。1–30 Hz全体に加え、必要に応じてalpha帯付近を拡大し、低周波側の巨大PSDによって小さいalpha峰が隠れていないか見る。拡大は表示だけで、追加平滑化や背景除去を行わない。
3. 周囲に比べて山が識別できるか、頂点の両側に下降があるか、代表となる峰を一つ指せるかを定性的に確認する。8/15 Hz近傍は帯域外側も見て、単なる切り出し端を頂点と誤認しない。
4. 複数の同程度の山で代表峰が曖昧、または広い周波数範囲に櫛状・律動的な小峰が続きalphaの一つの山を識別しにくい場合は、その所見を記録する。小さくても周囲と区別できる一つの山は明瞭になり得る。旧C/A/U/Mは観察記録として保持するが、それだけで最新の厳しい採否を代替しない。
5. 視覚的なalpha峰と保存IAFの選択峰が対応しているかも記録する。明瞭な山が別に存在していても、保存IAFが小峰・帯域端へ選ばれている疑いがあれば、その食い違いを明記する。評価中にIAFを差し替えない。
6. 区間を「明瞭」「不明瞭」「判断保留」「評価不能」に分け、理由と根拠区間を残す。表の凡例は **C=明瞭、A=判断保留、U=不明瞭、M=評価不能（PSD欠測）**。PSD欠測・有効窓0等は評価不能であって、ピーク不明瞭の証拠ではない。十分確認できない例を無理に二分しない。

数値の候補峰数・高さ・有効窓量等は、観察の補助・監査情報として使用できる。ただし、新しいz値・prominence・高さ・最低有効時間・明瞭区間数の割合などによる自動足切りは導入しない。今回の評価はCodexによる探索的な定性レビューであり、生理的alphaやノイズ原因を確定診断するものではない。

### 11.3 条件別評価とペア別の整理

各条件について、少なくとも1区間に明瞭な峰が確認できたか、明瞭な区間はどこか、その他に不明瞭・保留・評価不能の区間があるかをまとめる。その後、ペアを次のように整理する。

|---|---|---|
