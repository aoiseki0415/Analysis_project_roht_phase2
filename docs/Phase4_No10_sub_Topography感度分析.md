## 1. 目的・適用範囲

一部の個人の局所的な極端値が群topographyを強く左右する可能性に対して、**条件ごとの空間的孤立と時間的集中**を判定し、除外なし結果との感度を確認する。広い中央部の変化は大きさだけで除外せず、中央・円周の32chへ同じ規則を適用する。事後・探索的分析であり、生理的信号とノイズを確定診断する手法ではない。

| 対象・保持事項 | 確定内容 |
|---|---|
| 対象 | No10_sub、全32ch、Cキューブ／Vロートプレミアムの群topography |
| 開始集合 | 主subのbaseline適格39ペア。既知欠測は[注意事項](解析上の注意事項.md)と照合済みmanifestどおり |
| 除外単位 | ペア×ch×Set。片条件の該当を両条件へ適用するpaired OR |
| 独立性 | Fz/Pz線図・定量化の `SpecifiedPairsExcluded`、IAF採否、他Noの指定集合を継承しない |
| 保持 | 元cache、個人図、主要群図、No10本体、No11関連、他No |
| 行わないこと | Welch再計算、PSD補正・補間、新たな空間平滑化、ch別統計、仮説に合う分布への最適化 |

以前のNo1_sub–No3_subの補足手法は変更しない。v3はNo10_subだけの独立仕様である。旧v2の3経路を数値・境界条件とも維持し、新しいChange空間経路をORで加える。既存の除外セルを戻さないことを集合で検証する。

## 2. 入力・指標・参照集合

### 2.1 入力と描画値

1. No10の現行80 HDF5を読み取り専用で検証する。8/9/10 Hz、設定hash、Phase 1入力fingerprint、manifestのID・条件・製品を照合する。
2. Phase 1区間maskと帯域固有log3SD maskを再適用した**未平滑PSD**を使う。時刻を詰めず、NaNをゼロにしない。
3. セッションi、Set s、ch cの有限PSD窓をPとし、算術平均A、中央値D、有効窓数nを求める。
4. 同じ条件・ch自身のSet 1算術平均をBとし、`R = A / B`、Set平均の `PSD Change = 100 × (R − 1)` を求める。描画値は従来の未平滑Change平均と同値で、中央値baselineへ置換しない。
5. セッションごとの指標を判定してから、同じ被験者内の `Eye Drop − Control` を計算する。条件差そのものを除外閾値へ入力しない。

| 指標 | 定義・用途 |
|---|---|
| R | Set算術平均÷同条件・同chのSet 1算術平均。Changeの空間的孤立に使用 |
| D | Set内の有限PSD中央値。絶対PSDの高低と空間的孤立に使用 |
| H | A/D。短時間の大きなPSDに平均が左右される程度 |
| Q | 有限PSD n点の上位 `ceil(0.10×n)` 点の総和÷全有限点の総和。時間的集中に使用 |

対数・比に使う値は有限かつ正が前提。元のPSDに小さな定数を足したり、欠測を補ったりしない。計算不能な指標と元欠測は監査へ残し、値が存在するかのように判定しない。Qは実時間の割合ではなく、有限PSD窓数とそのパワー総和による指標。

### 2.2 近傍とrobust z

- MNEの既存 `colin27_1020` montageにおける**3D座標のユークリッド距離**で、各ch自身を除く最近傍4chを固定する。描画円の境界や2D画素の距離ではない。
- 比較対象XはRまたはD。各近傍jとの対数差を `d_j = log2(X_c) − log2(X_j)` とする。
- 局所残差は `L = log2(X_c) − median(log2(X_近傍4ch))`。中央値を取ってから対数化する方式とは区別する。
- robust zは `z(x) = (x − median(x)) / max(1.4826×median(|x−median(x)|), 0.15)`。0.15は**尺度の下限**であり、PSDへ足す値ではない。中央値・MADは有限値から求める。
- 空間z：同じセッション・同じSetの32chのLを参照。
- cohort残差z：同じSet・同じchのLについて、baseline適格な**両製品・両条件の全セッション**を参照。
- 絶対PSD水準z：同じSet・同じchの `log2(D)` のcohort参照。
- 平均／中央値z：同じSet・同じchの `log2(H)` のcohort参照。

両条件を参照集合へ含めることと、両条件を混ぜた値で異常判定することは別。**判定対象のR/D/H/Qは各セッション個別**であり、群集計も製品ごとに分離する。参照集合は元の適格集合で1回計算し、候補を除くたびに再推定しない。

## 3. 確定した除外規則

### 3.1 維持する条件側の3経路（旧v2と同一）

各経路内はすべてAND。この3経路に第3.2節の追加経路をORで結合する。空間・時間のどちらかを補助扱いにはしない。

| 経路 | AND条件 |
|---|---|
| Changeの空間的孤立（Set 2–6） | `abs(L_R) ≥ log2(1.5)`、`abs(空間z) ≥ 4.5`、`abs(cohort残差z) ≥ 4.5`、4近傍中3ch以上に対してL_Rと同じ方向へ1.25倍以上離れる、さらに下記の厳格近傍条件 |
| 絶対PSDの空間的孤立（Set 1–6） | `abs(L_D) ≥ 2`（4倍差）、`abs(空間z) ≥ 4.0`、`abs(cohort残差z) ≥ 3.5`、`abs(絶対PSD水準z) ≥ 4.0`、4近傍中3ch以上に対してL_Dと同じ方向へ2倍以上離れる、さらに下記の厳格近傍条件 |
| 時間的集中（Set 1–6） | `Q ≥ 0.50`、`H ≥ 3.0`、`平均／中央値z ≥ 3.5` |

空間経路の「同じ方向」とは、L>0なら `d_j ≥ log2(倍率)`、L<0なら `d_j ≤ −log2(倍率)` が3ch以上であること。各絶対値zの符号一致を別途要求するものではない。

**厳格近傍条件（空間2経路だけに適用）**

近傍4値を昇順に `x(1) ≤ x(2) ≤ x(3) ≤ x(4)` と並べ、

- 高方向：`X_c > 2 × x(3)`、または
- 低方向：`X_c < x(2) / 2`

を要求する。これは少なくとも3近傍から同じ方向へ**2倍を超えて**離れることに相当する。Change経路ではX=R、絶対PSD経路ではX=Dを使う。時間経路にはこの追加条件を要求しない。端／中央で閾値を変えたり、特定chを手動で免除・追加したりしない。

### 3.2 追加するChange空間経路（v3）

旧v2で残った局所差に対して、**同条件・同ch自身のbaselineからの変化、近傍からの孤立、cohortからの逸脱**を組み合わせる。各セッションのSet 2–6に以下をすべて要求する。

| 条件 | 確定値 |
|---|---|
| 自身のSet 1からの変化 | `R > 2` または `R < 0.5`。境界の2／0.5は含めない |
| 近傍からの孤立 | 最近傍4ch中3ch以上に対して、同方向へ**厳密に1.8倍超**離れる |
| cohortでの局所残差 | `abs(cohort残差z of L_R) ≥ 6` |
| 追加支持（いずれか） | `abs(同セッション・Set内の空間z of L_R) ≥ 3` **または** 最近傍4ch中3ch以上に対して同方向へ**厳密に3倍超**離れる |

近傍倍率fの厳密判定は、4近傍のRが有限・正のとき昇順に並べて `R_c > f × R_(3)` または `R_c < R_(2) / f`。実装では有限・正の近傍だけを支持票に数え、少なくとも3近傍を必要とする。欠測・非正値を支持票や0として補わない。f=1.8／3をそれぞれ独立評価し、高低両方向に同じ基準を使う。後者の3倍条件は空間z≥3を満たさない場合にも局所的孤立を確認するOR経路であり、cohort z≥6・自身のR変化・1.8倍条件を省略しない。

これは旧Change経路の4.5を3へ一律に緩める変更ではない。旧3経路の判定はそのまま残し、追加経路の該当セルを加える。特定ID・ch・製品専用の条件を作らず、参照分布は第2.2節どおり元の適格poolで固定する。Set 1にはこの追加経路を適用しない。

**現行に含めない条件：** 旧60秒blockの持続上昇／低下、固定500%／800%閾値、個人図の色軸上限、被験者全体の一律除外、Fz/Pz指定ペア除外、条件差の符号やp値。

### 3.3 Set 1・paired OR・群平均

1. 各セッション・ch・Setで上記を独立判定する。
2. Set 1で絶対PSD空間経路または時間経路に該当した場合は、baselineへの懸念として**同じセッション・同じchのSet 2–6**へ展開する。Set 1のRは1なのでChange空間判定は行わない。
3. どちらかの条件が該当したペア×ch×Setを**両条件から除外**する。別ch・別被験者へ広げない。
4. Set 1 topographyは従来の0を保持する。基準flagの伝播と表示を区別する。
5. 元から欠測のセルは新規除外数へ数えない。除外率の分母はSet 2–6で元々有限なペア×ch×Setセル。
6. 残存する被験者内差を製品×Set×chごとに等重み平均する。**chごとにN・構成員が異なる**ため、N表と採否を保存する。主要topographyの全32ch有限ペア方式は変更しない。

## 6. 解釈上の限界

- 本基準は結果確認後の探索的な感度分析で、独立データで検証されたノイズ判別器ではない。大きい値・局所色・条件差だけでノイズや製品効果を確定しない。
- v3追加経路は、実際に残った局所差を確認して採用した事後規則である。共通閾値でも独立した品質基準とは限らず、真の局所的な生理変化を除く可能性がある。
- 3/4近傍条件は広域の変化の過剰除外を抑えるが、空間的に滑らかなノイズや持続的な異常が残る可能性もある。候補外は正常の証明ではない。
- 全頭一様の倍率変化は局所残差から相殺されるが、広い中央領域の境界を常に保護できる保証ではない。滑らかさや群の最大値低下を採用の正解にせず、局所残差・絶対値・N・原図を併読する。
- 両製品・両条件を用いた参照分布は探索目的の頑健性確認。将来の独立検証で同じ妥当性を保証しない。
- 頭皮の円周色には描画補間も関与する。円周の色だけで存在しない電極を推定せず、実電極値・近傍・条件側指標を照合する。
- 除外後はchごとにNと構成員が変わる。滑らかさや仮説どおりの領域特異性を強制せず、原図と追加図を併記する。
- Fz／Pzの既存群線図・定量化とは対象集合が異なる場合がある。今回、それらの結果を黙って更新しない。
