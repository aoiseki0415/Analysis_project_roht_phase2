# 解析方針

## 1. 研究目的

本案件の目的は、**目薬の使用によって、ガボール課題中の注意力低下が抑えられるか**を調べることです。

単純な条件間平均だけでなく、実験の進行に伴う指標の悪化が、目薬あり条件でどの程度小さくなるかを重視します。

## 2. 目薬と実験条件

使用する目薬は次の2製品です。解析・文書では正式名称に統一します。

- Cキューブ（会話上「アクア」と呼ばれる場合がある）
- Vロートプレミアム（スプレッドシートでは「Vロート」、会話上「Vプレ」と呼ばれる場合がある）

各被験者は、どちらか一方の製品群に属します。各被験者は実験を2回行います。

- 目薬あり条件：割り当てられた製品を使用する
- 目薬なし条件：コントロール

したがって、製品は被験者間の群、目薬あり・なしは各被験者内の条件として扱う設計です。

実験データ総計および現在の解析使用予定は40名です。ID 130／230の被験者は総計に最初から含めず、現時点の解析対象外はこの1名のみです。ID 115／215はJSON非依存方針により使用します。ID 109／120／135／225も被験者としては使用しますが、Phase 1ではEEG欠測のあるセットを1つずつ除外し、問題のない残り5セットを前処理します。今後、解析別の品質基準で除外が生じた場合は、実使用人数を別途明記します。

## 3. 比較の単位

2製品を一つにまとめず、次の比較を別々に実施します。

1. Cキューブ群：Cキューブあり vs 目薬なし（コントロール）
2. Vロートプレミアム群：Vロートプレミアムあり vs 目薬なし（コントロール）

各比較で、それぞれの目薬が注意力低下を抑えるかを評価します。

## 4. 解析の5フェーズ

本解析は次の5フェーズに分けます。

1. 脳波の前処理
2. 行動データの解析
3. 瞬きの解析
4. 脳波の解析
5. 相関解析などその他

各フェーズでは、必要な場合を除いて2製品群を混合せず、Cキューブ群とVロートプレミアム群を分けます。各群内で、目薬あり条件と目薬なし条件（コントロール）を比較します。方針、実施内容、結果、解釈、未確定事項は、Notionの解析ストーリー配下にある対応するフェーズページへ記録します。

## 5. ガボール課題

- グレーのガボール刺激が円周上を時計回りに移動します。
- 途中でガボールが傾きます。これを刺激イベントとします。
- 被験者は傾きを検出したら、できるだけ早くボタンを押します。
- 刺激時刻と回答時刻から反応時間を算出します。
- 刺激が出ていないときのボタン押しは、ミスタッチとして記録されます。
- 1ブロック320試行、全6ブロックを実施します。
- 目薬あり条件では、ブロック間に目薬を使用します。正確な投与タイミングは実験資料と実データで確認します。

## 6. 注意力低下の評価軸

注意力低下は、ガボール課題中に取得された次の3系統から評価します。

1. 行動データ
2. 瞬き回数
3. 脳活動

共通する考え方は、実験進行に伴う変化を調べ、目薬あり条件で悪化の程度が小さいかを評価することです。期待される方向と、実際に観察された結果は明確に区別します。

## 7. 行動データ

主な指標は次のとおりです。

- 反応時間
- ミスタッチ

一般に実験が進むにつれて反応時間が遅くなることを想定します。目薬あり条件で反応時間の遅延が小さい場合、注意力低下が抑えられた状態を反映すると捉えます。

解析では全体平均だけでなく、ブロックまたは実験時間に対する反応時間の推移・傾き・変化量を重視します。ミスタッチについても、総数だけでなく実験進行に伴う推移を確認します。具体的な統計モデルと除外基準は、データ構造と解析方針を確認して別途定めます。

## 8. 瞬き

瞬きは脳波に含まれる瞬き成分から、ICAを用いて抽出する予定です。

一般に実験が進むにつれて瞬き回数が増えることを想定します。目薬あり条件で、その増加の程度が小さい場合、注意力低下が抑えられた状態を反映すると捉えます。

解析ではセットまたは時間区間ごとの瞬き回数と、その推移を評価します。Phase 1ではMNE-ICALabelの `eye blink` 確率0.90以上の成分だけを自動除去します。そのセンサー空間への寄与から得るFp1、Fp2、その平均信号をセット別に保存し、Phase 3の瞬き検出に使用します。

## 9. 脳活動

脳活動の具体的な指標と解析方法は、今後の相談で決定します。

現時点で確定している方針は次のとおりです。

- 試行ごとのepochingを主解析として用いない
- ブロック全体または実験全体を通して、脳活動がどのように変化するかを見る
- 実験進行に伴う変化が、目薬あり・なしで異なるかを評価する
- CキューブとVロートプレミアムを分けて解析する

## 10. 解析実装環境

- 本解析の新規実装にはPythonを使用します。
- MATLABは新規解析の実行環境には使用せず、既存のMATLABスクリプトは解析手順・手法を確認するための参考資料として扱います。
- Python 3.14.7を採用し、リポジトリ内の `.venv` を使用します。
- 依存関係は `pyproject.toml` と `uv.lock` で固定し、リポジトリ内のuvで同期します。
- 数値解析・表処理にはNumPy、SciPy、pandas、統計解析にはstatsmodelsとscikit-learn、可視化にはMatplotlibとSeabornを使用します。
- EEG解析の中核にはMNE-Pythonを使用します。EEGLAB形式の読み込み、連続EEGの前処理、ICA、可視化を行える構成です。
- ICA成分の分類にはMNE-ICALabelを使用し、EEGLAB由来のICLabelモデルから瞬き成分候補を得ます。
- ICAは固定乱数シードのextended Infomaxで実行します。瞬き・眼球由来ICはICLabel `eye blink` 確率0.90以上だけを完全自動で除去し、独自の複合特徴は除去判定に追加しません。
- 詳細な復元・実行・検証方法は `docs/Python環境.md` に従います。

2026年9月20日に、macOS 15.2（Apple Silicon）上でPython 3.14.7、MNE-Python 1.13.2、MNE-ICALabel 0.9.0を含む環境を構築しました。数値計算、連続EEG処理、extended Infomax ICA、ICLabelによる成分分類の動作を確認済みです。Apple Command Line Tools付属のPython 3.9.6は使用しません。
