# Phase 4 No12・No12_sub：意思決定・実装過程

記録開始：2026-11-16。本書は**議論・判断理由・実装過程の履歴**。実行に使う現行の確定仕様は[No12統合仕様](../Phase4_No12_解析仕様.md)、実行後の結果は同書第11節、詳細証跡はOneDriveのSubへ分離する。

## 1. 初回5電極版の目的と判断（履歴）

- Fz単極のlow-alpha解析に加え、Fzを含む前頭の複数電極で平均した指標を検討する目的でNo12／No12_subを追加する。
- 記録chを踏まえF3・Fz・F4・FC1・FC2を選択。FCz・F1・F2を仮想的に補間して追加しない。
- 利用者は、Phase 1不良区間を考慮したch別PSD時間変化に、ch別log3SDを適用してからch平均する順序を確認した。
- NaNの位置がch間で異なるため、有効chだけの時点別平均を採用した。5ch完備や最低ch数の追加足切りは設定しない。時点ごとのch構成が変わる限界を監査へ残す。
- 平滑化はch平均の後。subはROIの未平滑Set 1平均を基準に変化率へ変換してから同じ平滑化。定量化は未平滑ROI値を用いる。
- No10全32ch cacheを再利用できるためPSDを再計算・重複保存しない。ROI演算は専用の共通処理で再現する。
- No10／No11の細かな保存構造とFigure設定を維持。配色は利用者がチャコール／ミディアムグレーを承認し、Controlは既存深紫を継承した。
- 最初は追加被験者除外なし。後に信号品質を確認して必要なら追加版を検討する。他No・topographyの採否を自動で転用しない。
- Topography・TFMは生成しない。全32ch low-alpha mapは既存No10と重複するため。

## 2. 表現上の整理

対話中の「PSD時間変化→Phase 1除外」という略記は、不良区間を考慮せず解析する意味ではない。元cacheはmask前PSDを保持し、解析時に1%以上重なる不良窓を全chでNaNにした上で、ch別log3SD maskを適用する。今回もこの順序を守る。数値正本の保存と解析への採用を区別する。

## 4. 10電極への変更決定（2026-11-16）

### 4.1 議論・参照した情報

- 利用者はNo10_subのVプレtopographyで前頭の負の条件差が左右へ広がる所見を参考に、旧5電極の範囲を広げることを希望した。
- F7・F8を含む9電極、さらにC3・Cz・C4を含む12電極を候補として検討した。完成済みtopographyの電極別群値を平均する参考比較であり、新しいROIの個人時系列を算出した比較ではない。
- topographyはch別変化率の条件差で、除外対象もch別である。一方、No12_subは各IDの絶対PSDを先にch平均し、ROI自身のSet 1基準から変換する。候補比較の値と本番ROI値は一致を要求しない。
- 同じデータのtopographyを参照したROI選定であるため、後続結果は事後・探索的な評価とする。独立した確認的検証や特定領域の生理的同定に読み替えない。

### 4.2 確定した決定と変更範囲

- 変更するのはROI構成と、それに由来する数値・図・品質監査・設定識別。8–10 Hz、Phase 1窓mask、ID・ch別log3SD、有効ch等重み平均、ROI baseline、60点平滑化、定量化・統計・配色・Figure比率は維持する。
