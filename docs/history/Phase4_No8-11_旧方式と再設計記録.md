# Phase 4 No8–11：旧方式の廃止と再設計の記録

記録日：2026-11-10。**履歴専用。現行手順として使用しない。** 現行計算・Figure・保存仕様は[No8–11共有用解析仕様](../Phase4_No8-11_共有用解析仕様.md)を参照する。

## 出発点と最終判断

旧方式はPz/FzのSet別IAFと60秒区間・5秒移動IAFを計算した。背景補正・周波数平滑化・ピークz値・最低有効時間の判定によりNaNが多く、ユーザーが求める「まず元のPSD上の局所ピークとSet間推移を見る」探索と一致しなかった。旧計算の完了と、今回採用する手法を区別する必要が生じた。

| 論点 | 最終判断と理由 |
|---|---|
| 推定対象 | PzはNo8＝全Set、No9＝前後半。FzはNo10＝全Set、No11＝前後半。60秒の連続推移は廃止 |
| ピーク | 線形平均PSDの8–15 Hz局所最大のうち最高峰。帯域内argmaxではない |
| 採否 | z・背景補正・SG・顕著さ・最低coverageの追加足切りを廃止。Phase 1不良窓除外は保持 |
| 入力時間 | Set全体／前後半全体を対象に、10秒・50% overlap窓を平均。窓別IAF平均ではない |
| Figure | Eye Drop PSD、Control PSD、両条件IAFの3パネル。6本・12本の合成デザインを確認・承認 |
| 保存 | 旧結果と合成プレビューを現行結果から削除。旧IAF cacheも削除し、新schemaで再計算 |
| コード | 旧実装・テストは履歴層へ退避。新方式は別の計算契約で作るが、今回は実装しない |

旧品質基準を科学的に無価値と判断したのではない。今回は顕著さの厳密な選別より、局所ピークと元PSDの可視化を優先した。微小峰を拾うリスクは現行仕様へ明記する。
