# No10_sub topography感度分析 v2：判断・更新の経緯

2026-11-14。**議論と移行の記録。現在の実装に使う数値規則と実行結果は[現行補足仕様](../Phase4_No10_sub_Topography感度分析.md)の別節を正本とする。** 旧v1の全文・実績は[廃止版保存](Phase4_No10_sub_Topography感度分析_旧v1仕様結果_20261114.md)。

## 1. 観察と再検討の理由

- 旧v1はNo1–3で用いた条件別のSet 1絶対PSD高値・持続上昇・絶対低値を伴う持続低下をそのまま適用した探索的追加版だった。
- 利用者は、頭頂中央の広い領域が同じ方向へ変化する例まで除外される一方、円周付近の単一電極・狭い領域だけが近傍と異なる例が十分に拾われないことを懸念した。
- 広い範囲の変化は現象である可能性を保持する。局所色も条件差の図だけではノイズと断定できないため、Eye Drop／Controlそれぞれの入力値で確認し、差分図は判定の妥当性を検討するために使う方針とした。

## 2. 比較・意思決定

- 空間方向と時間方向は対立や主従ではなく、独立した候補経路として並列に置く。
- 空間はSet 1に対するSet平均比と絶対PSD中央値を用い、近傍4電極との差、同一Set内の他chとの比較、同一ch・同一Setの他セッションとの比較を組み合わせる。
- 時間はSet内の有限PSD窓で上位10%が占めるパワー比と平均／中央値を用い、集中した極端値の影響を検討する。旧60秒blockの持続変化経路は現行規則から外す。
- 初期候補は中央部も広く拾う懸念があった。そこで**空間経路に「4近傍のうち少なくとも3電極から同じ方向へ2倍を超えて離れる」条件を追加**した。中央電極だけ手動免除したり、円周電極だけ基準を緩めたりせず、32ch共通で適用する。
- チャット内の再試算では、前候補270セルから55セルが戻り、215セルとなった。新規候補の追加はなかった。この数値は本番実装・実行前の試算であり、完成成果物の実績とは区別する。
- 利用者は除外候補一覧とFz／Pz指定ペア追加版との関係を確認し、今回の手法をNo10_sub topography追加解析の基準として採用した。既存のFz／Pzの指定ペア集合を自動的に引き継ぐ方針ではない。

## 3. 採用の位置づけ

- 事後・探索的な感度分析。独立データで検証済みのノイズ分類器ではない。
- 目的は局所的な極端値に対する群平均の感度を見ること。仮説に合う領域、符号、有意性、滑らかな頭皮分布を得るように調整しない。
- 除外率や残存Nは妥当性を評価する材料であって、一定の除外率を達成するために逆算した閾値ではない。
- 空間的に滑らかなノイズや持続した広域の異常は残り得る。候補にならなかったchを正常と確定しない。
