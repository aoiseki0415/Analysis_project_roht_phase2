# No1_sub–No3_sub topography感度分析：2026-11-15の決定記録

本書は議論・意思決定の履歴。最新手法と本番結果は[現行補足仕様](../Phase4_PSDChange_Topography外れ値除外感度解析.md)の別節を参照する。旧方式・旧実績の全文は[保存版](Phase4_No123_sub_Topography感度分析_旧持続方式仕様結果_20261115.md)だけに残し、現行へ混在させない。

## 背景と検討の流れ

1. No10_subで、局所的な電極差と時間的集中を条件側から並列評価する空間・時間v3を確定した。
2. 利用者は同じ基準をNo1_sub・No2_sub・No3_subへ適用した場合の対象を、まずチャット内シミュレーションで確認するよう依頼した。
3. 既存cacheを変更せず、帯域別に同一4経路を適用した。比較フォルダのBefore/Afterと各No_subの対応PNGは同一であり、No1–3のAfterは当時まだ旧持続方式だったことを確認した。
4. 試算はNo1が311、No2が245、No3が435の元有限ペア×ch×Setを除外候補とした。No3で率が高く、No1 Cキューブのch別最小Nが13になることも共有した。ノイズ確定とは扱わない。
5. 利用者はこの方法で追加解析を更新し、各No_subと補足比較フォルダ双方の最新追加PNGを置換することを承認した。

## 今回確定した対応

- 文書の現行方法を先に更新し、その後に共通スクリプトを実装・実行する。
- 判定閾値はNo10v3と同じ。参照分布は各帯域の元の適格セッション集合から独立に固定計算する。
- 旧No1–3の持続方式maskは新maskへORしない。No10の除外ID/セルや線図・定量化の指定除外も転用しない。
- 原図・Before、個人結果、線図・定量化、PSD cache、No10／No11を保持する。最新追加図・Afterだけを更新する。
- 新版を検証して旧追加PNGを取り除き、旧CSV・JSON・LOGはhashと元相対パスを伴う非PNG履歴へ隔離する。旧PNGは履歴に複製しない。
- 方法、承認済み試算、本番結果、解釈・限界を別節にし、実行・照合・公開証跡はOneDrive Subへ記録する。匿名の個別候補はGitHub/Notionへ列挙しない。

## この記録が主張しないこと

特定の脳領域に仮説どおりの効果が出たこと、除外候補がすべてノイズであること、No10と同じ規則が別帯域でも独立検証されたことは主張しない。試算承認と本番出力の完了も区別する。

## 実装検証で判明した互換事項

最初のread-only dry-runでNo1のcache設定hash照合が停止した。原因は保存cacheがGit `3c7c25b`時点のschema（`analysis_stem`／`focus_channel`未導入）で作られていたこと。No1の期待hashだけをその既知schemaで再現し、全属性・実周波数binの検証は併用する方針とした。No2・No3は現行schemaに一致する。cache・PSD・除外閾値の変更や、照合不一致の無視で解決しない。失敗した事前検証と本番完了実績を区別する。
