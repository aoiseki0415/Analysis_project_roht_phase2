# Phase 3 瞬き検出：MAD係数8・10・12比較

> **履歴文書です。** 以下は4被験者ペアで行った初期比較と、当時k=10を選んだ判断を記録しています。その後、k=10による全対象の初回出力で過剰検出が確認されたため、現行の確定設定は **k=12** です。現在の運用は `docs/Phase3_瞬き解析仕様.md` を正本とします。

## 目的と比較条件

Prominence閾値 `median + k × 1.4826 × MAD` の係数 `k` を8・10・12で比較しました。比較以外の条件はすべて共通です。

- 対象被験者ペア：101–201、102–202、103–203、104–204
- 対象セッション：101、201、102、202、103、203、104、204
- 検出信号：1–10 Hzフィルタ後の `Fp1_Fp2_mean`
- Peak height：未設定
- Minimum peak distance：100 ms
- Peak width：20–320 ms
- 比較時は正式成果物を上書きせず、OneDriveの `Phase3_瞬き解析/No1_BlinkRate_ParameterComparison/` に分離した。最終決定後、探索用OneDrive成果物は削除した

## Codex目視評価

全8セッションについて、比較HTMLを用いてSet 1〜6をセット単位で走査しました。比較HTMLでは、k=12でも残るピーク、k=10で追加されるピーク、k=8でのみ追加されるピークを同じ波形上へ排他的に色分けしています。

- **k=8**：小振幅かつ基線近傍の追加検出が複数セッションで増えました。特にID104ではk=10より17.3%増え、追加分には瞬きらしい形が明瞭でないピークが目立ちました。3条件中では過検出リスクが最も高いと評価します。
- **k=12**：大きく明瞭なピークは安定して残ります。一方、ID101、ID203、ID104ではk=10で検出されていた中振幅の瞬き様ピークまで一部落ち、見落としリスクが増えました。特にID203はk=10より7.8%減少しました。
- **k=10**：k=8で増える基線近傍の小ピークを多く抑えつつ、k=12で落ちる中振幅の瞬き様ピークを比較的保持しました。8セッションを共通設定で扱う場合、感度と過検出の均衡が最もよいと評価しました。

この評価は波形形状に基づく目視QCであり、真の瞬きラベルとの照合による感度・適合率ではありません。利用者が4被験者ペアを独立に目視確認した結果と突合し、正式係数を **k=10** に確定しました。
